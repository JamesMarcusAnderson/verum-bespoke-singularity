# Security Policy

## Reporting a vulnerability

Please report suspected security issues **privately** — do not open a public
issue for them.

- Email: **jamesmarcusanderson@protonmail.com**

I'll acknowledge receipt and work with you on a fix and a disclosure timeline.

## Scope note

This repository documents hardware security research performed on my own
devices — read-only unless the README states otherwise. Published findings
are defensive and educational.
